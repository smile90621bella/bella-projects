# 金拾煎 訂單系統：Google Sheet ＋ Apps Script 設定教學

網站結帳 → Apps Script（GAS）→ Google 試算表。整個設定大約 10 分鐘，只需要做一次。

## 流程

```
客人在網站按「確認送出訂單」
        │  （只送品項代碼與數量，不送價格）
        ▼
Google Apps Script（doPost）
  ├─ 檢查資料：姓名、手機、地址、品項、數量
  ├─ 依「菜單」工作表重新計價（網頁上的價格被改也沒用）
  ├─ 產生訂單編號：JSJ年月日-流水號，例如 JSJ261116-007
  ├─ 寫入「訂單」「訂單明細」
  └─ 寄信：通知店家；客人有填 Email 就寄確認信
        │
        ▼
網站顯示「訂單已建立」與訂單編號
```

## 試算表內容

| 工作表 | 說明 |
|---|---|
| 訂單 | 一筆訂單一列。「狀態」欄可用下拉選單切換，顏色會跟著變 |
| 訂單明細 | 一個品項一列，方便做統計或樞紐分析 |
| 菜單 | 網站計價依據。**改價格、下架（上架欄填 N）直接改這裡**，不用改程式 |
| 錯誤紀錄 | 系統出錯時的紀錄，平常是空的 |

## 自動化功能

- **新訂單通知**：每筆訂單寄信給店家，信裡有明細和試算表連結。
- **客人確認信**：客人有填 Email 才會寄。
- **狀態通知**：把「狀態」改成 **可取餐**、**已出貨** 或 **已取消** 時，自動寄信給客人，並在「通知紀錄」欄留下時間。
- **營業日報**：每天 21 點左右寄出當日訂單數、營業額、各取餐方式與各門市金額，以及熱銷前 5 名。
- **防護**：
  - 同一筆訂單重送不會重複建立。
  - 同一支電話 10 分鐘內最多下 5 單。
  - 有隱藏欄位擋機器人。
  - 擋掉試算表公式注入。

## 設定步驟

### 1. 建立試算表與程式
1. 到 [Google 試算表](https://sheets.google.com) 新增一個空白試算表，取名例如「金拾煎訂單」。
2. 上方選單 **擴充功能 → Apps Script**。
3. 刪掉編輯器裡原本的內容，把本資料夾的 `Code.gs` **整份貼上**，按儲存（💾）。
4. （選用）把 `Code.gs` 最上面 `CONFIG` 裡的 `NOTIFY_EMAIL` 改成要收通知的信箱。留空的話，會寄到你自己的 Google 帳號。

### 2. 執行 setup（只要一次）
1. 編輯器上方的函式選單選 **setup**，按 **執行**。
2. 跳出授權視窗時，選你的 Google 帳號。如果出現「Google 尚未驗證這個應用程式」，請按 **進階 → 前往（不安全）→ 允許**。這個程式是你自己的，只會存取這份試算表和用你的信箱寄信。
3. 回到試算表，會看到「訂單」「訂單明細」「菜單」「錯誤紀錄」四個工作表。

### 3. 部署成網址
1. 右上角 **部署 → 新增部署作業**。
2. 齒輪 ⚙ 選 **網頁應用程式**。
3. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**（客人不用登入 Google 也能下單）
4. 按 **部署**，複製「網頁應用程式網址」（結尾是 `/exec`）。

### 4. 填到網站
打開 `index.html`，找到這一行：
```js
const ORDER_API = '';
```
把網址貼進引號裡：
```js
const ORDER_API = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```
存檔並推送。網址留空的話，網站維持「示範模式」，不會真的送出訂單。

### 5. 測試
- 在 Apps Script 編輯器執行 **testCreateOrder**，會建立一筆測試訂單並寄信給你。測完可以刪掉那一列。
- 在網站實際下一單，確認試算表有新增資料、信箱有收到通知。
- 把那筆訂單的狀態改成「可取餐」，確認客人信箱收到通知。

## 之後修改程式要注意
在 Apps Script 改了 `Code.gs` 之後，要到 **部署 → 管理部署作業 → ✏️ 編輯 → 版本：新版本 → 部署**，網站才會用到新程式。這樣操作網址不會變。

## 限制
- 免費 Gmail 帳號每天大約能寄 100 封信，Google Workspace 帳號約 1,500 封。
- 網站不做線上付款：門市取餐現場付款，宅配的付款方式需要店家另外聯繫客人確認。
